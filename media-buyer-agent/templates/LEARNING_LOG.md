# Journal d'apprentissage

Ce journal est la mémoire de la stratégie. Le mettre à jour à chaque cycle (test terminé, post-mortem, décision de budget), et le recoller en début de session suivante pour que la Skill reparte de ce qui est déjà appris.

Règles :
- Une entrée = un fait, une hypothèse ou une décision. Ne pas mélanger.
- Une hypothèse abandonnée reste dans le journal, avec la donnée qui l'a contredite.
- Une idée gagnante est notée avec son **mécanisme** (pourquoi elle marche), pas seulement avec son nom.
