# Conformité et honnêteté de la fiche

Charger pour : l'autocontrôle de chaque fiche.

Une fiche qui ment convertit une fois, puis génère refus à la livraison, remboursements, mauvais bouche-à-oreille et comptes publicitaires bloqués. En paiement à la livraison, chaque promesse non tenue coûte un aller-retour de livreur.

## 1. Interdits

| Interdit | Pourquoi | Version acceptable |
|---|---|---|
| Témoignage, nom ou ville inventés | Tromperie ; se voit vite | `[À REMPLIR : témoignage réel]` |
| « Guérit », « soigne », « traite » | Allégation médicale | « Aide à réduire », « conçu pour soulager » |
| « Résultat garanti », « 100 % efficace » | Invérifiable | « Dès les premières nuits, beaucoup de clients constatent… » (si c'est vrai) |
| Faux compte à rebours, faux stock | Fausse urgence | Promo réelle avec date de fin, ou urgence naturelle |
| Prix barré jamais pratiqué | Prix de référence trompeur | Pas de prix barré, ou « prix habituel » réel |
| « Or », « acier inoxydable », « étanche », « suisse », « automatique » non vérifiés | Fausse caractéristique → refus à la livraison | Écrire seulement ce que le fournisseur confirme ; sinon `[À VÉRIFIER]` |
| Nom ou logo d'une marque connue, « style Rolex » | Contrefaçon / marque déposée | Décrire le style : « cadran bleu nuit, bracelet acier » |
| Garantie ou remboursement que la boutique n'applique pas | Promesse non tenue | Ne mentionner que ce que l'utilisateur confirme |

## 2. Si la page reçoit du trafic Meta

La page de destination est aussi examinée par Meta. Éviter :
- Les promesses de santé ou de perte de poids exagérées, avant/après trompeurs.
- Les affirmations d'attributs personnels dans les **publicités** (« Vous ronflez ? » est acceptable sur la page, risqué dans le texte de la pub — voir `media-buyer-agent/references/META_AD_POLICY.md`).

## 3. Étanchéité, matériaux, compatibilités

Pour les produits techniques (montres, électronique) : distinguer clairement **résistant aux éclaboussures** / **étanche 3 ATM** / **étanche pour nager**. Une erreur ici = retours garantis. Demander la fiche fournisseur si elle n'est pas fournie.

## 4. Checklist conformité

- [ ] Chaque témoignage est réel ou marqué `[À REMPLIR]`
- [ ] Chaque chiffre vient de l'utilisateur ou est marqué `[À VÉRIFIER]`
- [ ] Aucune promesse médicale ni garantie absolue
- [ ] L'urgence est vraie
- [ ] Aucune marque tierce citée
- [ ] Les caractéristiques techniques correspondent à ce que le fournisseur confirme
