# Brief fiche produit

À remplir (ou à copier-coller) pour obtenir la meilleure fiche. Seuls **produit** et **angle** sont indispensables ; le reste améliore le résultat.

```
PRODUIT :            (nom + ce qu'il fait concrètement)
PHOTOS / LIEN :      (lien fournisseur, photos, vidéo)
CARACTÉRISTIQUES :   (matière, taille, couleur, étanchéité, batterie… ce que le fournisseur confirme)
PRIX DE VENTE :      (+ prix barré s'il est réellement pratiqué)
OFFRE :              (lot 2 = …, cadeau offert, livraison gratuite…)
PAYS / VILLES :
CIBLE :              (qui achète ? pour soi ou pour offrir ?)
ANGLE MARKETING :    (la raison d'acheter à mettre en avant)
HOOK DE LA PUB :     (si une pub existe déjà, sa phrase d'accroche)
PAIEMENT :           (à la livraison ? mobile money ?)
LIVRAISON :          (délai, zones, frais)
GARANTIE / RETOUR :  (ce qui est réellement appliqué)
CONTACT :            (WhatsApp, téléphone)
PREUVES DISPONIBLES: (avis, captures WhatsApp, vidéos clients, nombre de ventes)
URGENCE RÉELLE :     (promo jusqu'au …, stock de …, événement à venir)
PLATEFORME :         (Shopify, YouCan, WooCommerce, landing page…)
LONGUEUR SOUHAITÉE : (complète / courte / juste le titre…)
```
