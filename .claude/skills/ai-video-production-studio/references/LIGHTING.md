# LIGHTING : une source motivée

Chaque lumière doit avoir une origine dans le décor : fenêtre, lampe, soleil, écran. Une lumière sans source crédible rend l'image artificielle.

## Lumières de base

| Ambiance | Source motivée | Effet |
|---|---|---|
| Naturelle douce | Fenêtre à gauche ou à droite, jour nuageux | UGC, lifestyle, véridique |
| Golden hour | Soleil bas, extérieur | Émotion, lifestyle chaleureux |
| Studio doux | Grande source frontale diffuse | Produit propre, démonstration |
| Dramatique | Source latérale unique, ombre marquée | Cinéma, mystère, luxe sombre |
| Néon / urbain | Enseignes, écrans | Ambiance nocturne, mode |
| Intérieur quotidien | Lampe plafonnier, lumière mixte légèrement jaune | Faceless, UGC domestique |

## Température de couleur

- Chaude (2700–3500 K) : intimité, lifestyle, nostalgie.
- Neutre (4000–5000 K) : propreté, démonstration, produit.
- Froide (6000 K et plus) : technologie, tension, luxe moderne.

Garder une seule température par scène et une cohérence d'une scène à l'autre.

## Peaux foncées et lumière

- Éviter la surexposition : les hautes lumières délavent et font perdre les détails du visage.
- Une source douce et latérale modèle mieux que la lumière frontale plate.
- Vérifier que le visage reste lisible dans les ombres sans être éclairci artificiellement.
- Ne pas utiliser de lumière « flatteuse » qui blanchit ; viser une lumière naturelle et uniforme.

## Produit

- Un reflet doit correspondre à la source déclarée dans la scène.
- Pour métal, verre, cadran : une source de taille moyenne donne des reflets lisibles. Une source trop petite crée des points lumineux parasites.
- Un produit sombre a besoin d'une contre-lumière ou d'un fond clair pour sortir.

## Erreurs fréquentes à prévenir

- Deux sources incohérentes (une chaude à gauche, une froide à droite sans raison).
- Ombre qui change de direction entre deux plans du même lieu.
- Contre-jour qui cache le visage d'un personnage censé parler.
- Lumière « studio » sur un UGC : le spectateur sent la pub.
