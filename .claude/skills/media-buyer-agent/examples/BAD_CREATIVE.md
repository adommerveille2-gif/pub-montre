# Exemple : mauvais script et sa correction (mode M3)

> Produit **fictif** : « Cube compressible FICTIF ». Le script ci-dessous est volontairement faible pour montrer la critique.

## Script soumis par l'utilisateur

```
[0-3 s] Logo de la marque, musique épique.
[3-8 s] Voix off : « Découvrez le cube compressible révolutionnaire ! »
[8-15 s] Liste à l'écran : compact, léger, résistant, pratique, élégant.
[15-22 s] Voix off : « Ne perdez plus jamais vos affaires ! Résultats garantis ! »
[22-30 s] « -50 % aujourd'hui seulement ! Stock limité ! Cliquez maintenant ! »
```

## Critique (mode M3)

**1. Ce qui fonctionne** : la durée (30 s) est raisonnable pour un test. Le produit est identifiable.

**2. Ce qui est faible** :
- 0–3 s : logo et musique épique. Aucune situation, aucune raison de continuer. Le spectateur part probablement avant la première information.
- 3–8 s : « Découvrez… révolutionnaire » est le hook générique qui signale la publicité.
- 8–15 s : une liste de cinq adjectifs. Aucun adjectif n'est démontré.
- 15–22 s : « Résultats garantis » est une promesse non vérifiable et non fournie.
- 22–30 s : « -50 % aujourd'hui seulement », « Stock limité » : réduction et rareté non fournies, risque de fausse urgence.

**3. Ce qui manque** : une situation reconnaissable, une démonstration, une preuve réelle, une objection traitée (« est-ce que ça tient vraiment ? »), un CTA lié à une promesse précise.

**4. Pourquoi le spectateur part** : 0–3 s sans enjeu, 3–8 s publicité reconnue, 8–15 s liste sans preuve. Abandon probable avant 5 secondes.

**5. Renforcer l'identification** : ouvrir sur une scène concrète (valise qui ne ferme plus, bagage qui déborde à l'enregistrement).

**6. Réduire l'impression de publicité** : supprimer le logo au début, la musique épique, la voix corporate, la liste d'adjectifs.

**7. Augmenter le désir** : montrer la transformation (la valise qui se referme, le voyageur qui passe la file), pas le produit seul.

**8. Renforcer la preuve** : une démonstration de compression en un plan. Si un avis réel existe, il doit venir d'un client identifié qui a donné son accord. Aucun chiffre inventé.

**9. Améliorer la fin** : supprimer les trois promesses (résultats, réduction, stock). Terminer sur l'action liée à la démonstration.

**10. Version améliorée** :

```
[0-3 s] Comptoir d'aéroport. Un voyageur force sur sa fermeture, les affaires débordent.
        Texte à l'écran : « Le moment où toute la file regarde ta valise. »
[3-8 s] Il sort le cube compressible, range en quelques gestes, comprime.
[8-15 s] La valise se referme. Plan large sur la file qui avance.
[15-25 s] Gros plan sur la fermeture, le voyageur reprend sa route. Texte : « Tout tient, la fermeture aussi. »
[25-30 s] Produit et CTA : « Voir la démonstration complète ».
```

Corrections signalées :
- Promesses non fournies (« résultats garantis », « -50 % », « stock limité ») supprimées. Si une réduction réelle existe, elle doit apparaître sur la page avec le prix de référence réel.
- Musique et logo déplacés ou retirés des premières secondes.
- Hook remplacé par une situation.

**Conformité** : version initiale à risque élevé (fausse urgence, promesse non vérifiable, réduction non fournie). Version améliorée : risque faible, sous réserve que la démonstration soit réelle.

**Test recommandé** : hook situationnel contre hook démonstration, même corps de vidéo. Métrique principale : hook rate. Garde-fou : taux de chargement de la page.

## Ce qui n'est pas dit

- Le script n'est pas jugé « mauvais » en bloc : il est analysé point par point. C'est le ton attendu.
- La réduction et le stock ne sont pas validés. Ils sont signalés comme `Information manquante`.
