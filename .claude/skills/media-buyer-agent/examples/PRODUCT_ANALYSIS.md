# Exemple : analyse produit condensée (mode M1)

> Produit **fictif** : « Cube compressible FICTIF », vendu 40 € hors promotion. Marché : **non précisé dans cet exemple**. La Skill demanderait le pays avant de finaliser les étapes marché et paiement.

## Entrées fournies

- Nom, description : cube de rangement souple, compression par fermeture à glissière.
- Prix : 40 €. Coût produit : **non fourni**. Livraison : **non fournie**.
- Preuves : **aucune preuve fournie** (ni avis, ni démonstration vidéo).
- Objectif : rentabilité.

Information manquante bloquante : coût produit, livraison, marge (bloque le break-even), pays (bloque l'analyse de marché), preuves réelles (limite les promesses).

## Grille d'analyse (extrait)

| Dimension | Réponse | Statut |
|---|---|---|
| Caractéristiques | Tissu, glissière, compression | FAIT (description fournie) |
| Fonctionnalité | Réduit le volume des vêtements dans la valise | HYPOTHÈSE (à démontrer) |
| Bénéfice fonctionnel | Valise qui ferme, affaires organisées | HYPOTHÈSE |
| Bénéfice émotionnel | Sérénité au moment de partir, pas de gêne en public | HYPOTHÈSE |
| Bénéfice social | Image de voyageur organisé | HYPOTHÈSE |
| Transformation | Passer de la valise qu'on force à la valise qu'on referme | HYPOTHÈSE |
| Frustration | Valise qui cède, affaires qui débordent | HYPOTHÈSE à valider par commentaires |
| Conséquence de l'inaction | Retard, gêne, vêtements froissés | HYPOTHÈSE |

## Chaîne de motivation

1. Pourquoi acheter ? Pour que la valise ferme et que les affaires restent en place.
2. Pourquoi cette raison compte-t-elle ? Parce que le moment de fermeture arrive devant les autres, au pire moment.
3. Motivation plus profonde (hypothèse) : ne pas se sentir désorganisé en public.

Arrêt de la chaîne : l'émotion est exprimable dans le langage du client. Statut : hypothèse à tester.

## Points de vigilance

- Sans preuve réelle, les angles « témoignage » sont exclus pour l'instant.
- Sans coût produit et sans livraison, aucune cible CPA n'est proposée.
- Les angles de réserve demandent une démonstration : sans elle, ils restent faibles.

## Plan de test (extrait)

- Test 1 (PRIORITAIRE) : hook situationnel contre hook démonstration, même angle de corps. Une variable : le hook.
- Test 2 (SECONDAIRE) : format scène de vie contre format UGC problème / solution, même hook.
- Données à demander avant lancement : pays, coût produit, livraison, frais de paiement.
